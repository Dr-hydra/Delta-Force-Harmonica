# 云存档批量罗技宏

从导航进入「批量导出」（`?view=batch`）。在支持 Toy CloudStorage 的 B站 Toy 环境中读取「我的云存档」，按想要的顺序逐首勾选。右侧歌单的编号就是导出脚本的歌曲编号；搜索不改变已选顺序，移除再选会追加到末尾。

点击导出后，页面逐首读取完整云存档，沿用现有单音整理、移调、指法优化和按键编排规则，下载一个 `云存档歌单-logitech-batch.lua`。如果任意一首读取失败、分片损坏或没有可演奏音符，本次不生成文件，以免歌曲编号发生变化。读取失败会保留选择，支持重试。

## 按键操作

- 开始键设置与单首导出一致：鼠标 1–20 或罗技键盘 G1–G18。
- 连按 N 次选择第 N 首。鼠标 1–5：最后一次松开后停按 700 毫秒，自动开始播放。其他鼠标键及键盘 G 键：最后松开后停按至少 700 毫秒，再按一次开始键确认播放。
- 按住只计一次。超过歌曲总数会取消本轮，不循环回第一首。
- 切换设置的 Caps Lock、Scroll Lock 或 Num Lock，可取消选歌或停止播放；播放前已经开启该锁定键不会影响启动。
- 每次播放或取消后留有 800 毫秒冷却，下一轮重新从第 1 首计数。

在 G HUB 的配置文件脚本编辑器中粘贴内容并保存。脚本开头附编号歌单，编辑器日志也会显示当前选择的编号和歌名。鼠标 1–5 使用按键状态轮询；其他按键使用按下/松开事件计数，因此需要额外一次确认。鼠标编号沿用原界面的 OnEvent 编号，轮询时转换右键/中键编号；左键会启用事件上报。批量设置独立保存，不改写原有单首导出设置。

## 实现与验证

`src/export/logitechBatch.ts` 是独立导出器，歌曲保存为动作数组，由一个播放器循环执行。每个动作包含延迟、输入编号和按下/松开状态，保留跨音符修饰键行为。等待期间最多每 10 毫秒检查停止状态；实际响应与节奏仍受 G HUB 和系统调度影响。

`src/export/logitechBatch.test.ts` 使用仅用于开发测试的 Fengari Lua VM，模拟 G HUB 按键和时间接口，检查连按计数、长按、越界取消、停止、释放按键、输入异常、重复事件及标题转义。该 VM 使用 Lua 5.3 语义，生成脚本仅使用与 Lua 5.1 兼容的基础语法；测试不能代替 G HUB 实机验证。

原有单首 Lua 导出器、雷蛇导出器及导出面板保持不变；已有页面仅增加新页面的导航入口。
